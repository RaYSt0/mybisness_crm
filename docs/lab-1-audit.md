## Общие требования, которые нельзя закрыть только кодом

- Согласование темы с преподавателем: подтверждения нет.
- Удалённый репозиторий и доступ преподавателю: адрес и платформа не предоставлены, публикация не выполнена.
- Регулярная история разработки: в исходной папке Git отсутствовал. Текущий коммит не может восстановить старую историю.
- Запрет генерации кода ИИ: доработка выполнена с ИИ-помощью по запросу владельца; этот пункт не соблюдён. В исходном README_AI.md также уже было описание предыдущих доработок с ИИ.
- FastAPI, PostgreSQL и SQLAlchemy обязательны для проекта в целом, но не входят в реализацию лабораторной №1. Указанный в старом README_AI.md план Node.js заменён на стек методички.

## Проверка перед демонстрацией

Запустить `npm ci`, `npm run build`, затем установить Chromium (`npx playwright install chromium`) и выполнить `npm run test:e2e`. Вручную показать главную → список → поиск → профиль → вкладки → конструктор → выключение финансов → перезагрузка → настройки → просмотр прав. Повторить основные переходы на узком экране. Данные на этом этапе могут быть демонстрационными.

## Результат проверки 13 сентября 2026

`npm run build` прошёл (включая строгую проверку TypeScript). Три сценарных теста Playwright прошли в Chromium: основные экраны проверены на 1440 и 390 px; сохранено 23 скриншота. Просмотр скриншотов выявил сжатие мобильных таблиц и незавершённую анимацию графиков; оба замечания исправлены, проверки повторены. Vite сообщает о крупном JS-файле сборки; для текущего frontend-прототипа это не блокирует запуск.
